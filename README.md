# 📱 Pokédex em React Native

Uma simples Pokédex desenvolvida com **React Native**, que consome dados da [PokéAPI](https://pokeapi.co/) para listar e exibir informações dos Pokémon.

---

## 🔍 Funcionalidades

- 🔄 Lista de Pokémon com scroll infinito
- 🔎 Busca por nome ou número
- 📄 Exibição de detalhes (imagem, tipos, habilidades etc.)
- 💡 Interface responsiva e amigável
- ⚡️ Carregamento dinâmico via API

---

## 🚀 Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) (opcional, se aplicável)
- [Axios](https://axios-http.com/) ou `fetch` para requisições HTTP
- [React Navigation](https://reactnavigation.org/) para navegação entre telas
